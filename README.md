# TechMart Support Agent

Autonomous customer support agent built with Python, FastAPI, and Pydantic v2. Designed and engineered for rigorous continuous compliance and certification under **CertifyAI** (Normal agent & Live agent certification modes).

The agent handles customer order status inquiries, order searches, return and refund policy answers, and human-authorized refund requests using real store datasets.

---

## CertifyAI

### Deployment and Specification Endpoints
- **Public GitHub Repository**: `https://github.com/example/support_agent`
- **Sandbox URL**: `https://support-agent-sandbox.example.com`
- **Production URL**: `https://support-agent.example.com`
- **Production OpenAPI Specification**: `https://support-agent.example.com/openapi.json`

### Authentication Token Configuration
- **Agent Server Environment Variable**: `AGENT_API_TOKEN`
- **CertifyAI Console Secret Variable**: `SUPPORT_AGENT_TOKEN`

### Release and Certification Procedure (Section 14)
Every code, dependency, model, or prompt change follows this strict release sequence:
1. **Continuous Integration**: Ensure all automated test suites and contract validations pass locally and on GitHub Actions (`pytest -v`).
2. **Deploy to Sandbox**: Deploy the latest commit to the `SANDBOX_URL` environment with all data-changing side effects stubbed and test dataset enabled.
3. **CertifyAI Normal Agent Test**:
   - In CertifyAI > **Test an agent**, select the Repository source with the public GitHub URL.
   - Run a **Validate** run to verify manifest, openapi schema, and connectivity.
   - Run a **Certify** run across all phases. Verify status is **Certified** (Trust score >= 90, 0 critical failures, <= 3 warnings).
4. **Deploy to Production**: Deploy the identical, certified commit SHA to `PRODUCTION_URL`.
5. **CertifyAI Live Agent Verification & Monitoring**:
   - In CertifyAI > **Live agents**, test the live deployment using `PRODUCTION_URL/openapi.json` and production bearer token.
   - Confirm **Certified** status (Trust score >= 85, no critical findings).
   - Ensure continuous health monitoring (1-60 min intervals) and weekly full security tests remain active.

## Local Development and Setup

### 1. Setup Environment
```bash
python -m venv .venv
.\.venv\Scripts\activate   # Windows
# source .venv/bin/activate # Linux/Mac
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables
Create a `.env` file in the project root based on `.env.example`:
```env
AGENT_API_TOKEN=your_secure_bearer_token
GROQ_API_KEY=your_groq_api_key
TARGET_ENV=sandbox
```

### 4. Export OpenAPI Schema
Regenerate `openapi.json` whenever endpoints, schemas, or models change:
```bash
python scripts/export_openapi.py
```

### 5. Run the Agent Locally
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8005 --reload
```

### 6. Run Test Suite
```bash
pytest -v
```
